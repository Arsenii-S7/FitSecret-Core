# FitSecret-CLI (v1.0)

Интерактивное консольное приложение на Python для точного подсчета калорий и макронутриентов (КБЖУ). 
Создано специально для спортсменов и любителей фитнеса для контроля питания.

## 🚀 Основные фичи:
* **Умная база данных**: Предустановленный список продуктов со спортивным уклоном (мясо, крупы в сыром виде, спортпит).
* **Кулинарные меры**: Возможность вводить еду не только в граммах, но и в штуках, ложках и скупах протеина.
* **Эксклюзивные продукты**: Динамическое добавление новых продуктов прямо через консоль с сохранением в локальную базу данных (`food_db.json`).
* **Дневник питания**: Автоматическая запись истории приемов пищи по датам в файл `meal_history.json` с возможностью просмотра суммарного КБЖУ за день.

## 📦 Как запустить:
1. Склонируйте репозиторий или скачайте `main.py`.
2. Запустите через терминал: `python main.py`
